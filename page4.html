เรียนรู้ Cloud Storage

1แนวคิดพื้นฐาน

เปรียบ Cloud Storage เหมือน "กระเป๋าตังค์ดิจิทัล" หรือ "ตู้แฟ้มกลาง" ที่ไม่ได้วางอยู่ในคอมพิวเตอร์ แต่อยู่บนอินเทอร์เน็ต ทำให้เปิดดู แก้ไข หรือส่งไฟล์ให้เพื่อนได้จากทุกอุปกรณ์ ไม่ว่าจะใช้มือถือ แท็บเล็ต หรือคอมพิวเตอร์

เปรียบเทียบกับชีวิตจริง
เมื่อก่อนต้องพก
Flash Drive
(หายง่าย/ติดไวรัส)
→
ยุคนี้เซฟลง Cloud
(ไม่หาย/เปิดได้ทุกที่)

2บริการ Cloud ใกล้ตัว

Google Drive / Google Docs
ใช้ทำรายงานกลุ่มส่งครูพร้อมกันหลายๆ คนได้แบบเรียลไทม์
iCloud / Google Photos
สำรองรูปถ่ายและวิดีโอจากมือถืออัตโนมัติ ไม่ต้องกลัวเมมโมรี่เต็ม
OneDrive
แหล่งเก็บไฟล์เอกสาร Word, PowerPoint บนระบบของ Microsoft
Cloud Gaming
(เช่น Steam / Roblox)
เซฟด่านเกมล่าสุดที่เล่นไว้ พอเปลี่ยนไปเล่นเครื่องอื่นก็เล่นต่อจากเดิมได้ทันที

3ข้อดีและสิ่งที่ต้องระวัง

ข้อดีของการใช้ Cloud
Work Anywhere
ทำงานได้ทุกที่ที่มีอินเทอร์เน็ต

Real-time Collaboration
แก้งานกลุ่มกับเพื่อนได้พร้อมกัน ไม่ต้องส่งไฟล์ไปมา

Auto Backup
ข้อมูลไม่หายแม้อุปกรณ์พังหรือโทรศัพท์ตกน้ำ
ข้อควรระวัง
ต้องมีอินเทอร์เน็ต
ถ้าไม่มีเน็ต จะเข้าถึงไฟล์ไม่ได้

พื้นที่ฟรีมีจำกัด
หากเต็ม ต้องลบไฟล์ที่ไม่ใช้ หรือเสียเงินซื้อเพิ่ม

ความปลอดภัย
หากรหัสผ่านถูกแฮก คนอื่นก็อาจแอบดูไฟล์เราได้
