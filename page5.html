การเขียนเว็บพื้นฐาน

13 เสาหลักของการสร้างเว็บ (The Big 3 Trio)

HTML (Structure - โครงสร้าง)
เปรียบเหมือน "เสา" ของบ้าน ใช้ใส่ข้อความ รูปภาพ ปุ่มกด และจัดลำดับเนื้อหา
CSS (Style - การตกแต่ง)
เปรียบเหมือน "เสื้อผ้าและสีทาบ้าน" ใช้ตกแต่งใส่สี ปรับฟอนต์ จัดขนาด และวางเลย์เอาต์ให้สวยงาม
Bootstrap - กล่องเลโก้สำเร็จรูป

เครื่องมือช่วยสร้างเว็บที่เปรียบเหมือนตัวต่อสำเร็จรูป มีปุ่ม เมนู และการ์ดให้หยิบมาใช้ได้ทันที โดยไม่ต้องเขียน CSS เองตั้งแต่ต้น
รองรับทุกหน้าจอ (Responsive): แสดงผลสวยงามบนมือถือ แท็บเล็ต และคอมพิวเตอร์

Bootstrap Details
Grid System
(1-12) ช่วยจัดวางเนื้อหา และรูปภาพให้เป็นระเบียบ
Components
Navbar, Cards, Buttons ใช้ทำเมนูนำทาง กล่อง และปุ่มกดสีสันต่างๆ ได้อย่างรวดเร็ว
การเรียกใช้ด้วย CDN
นำมาใช้งานได้ง่ายๆ เพียงก๊อปปี้ลิงก์ของ Bootstrap มาวางในโค้ด HTML

2แท็ก HTML พื้นฐานที่ต้องรู้

แท็กที่ใช้บ่อยที่สุด ส่วนใหญ่มีแท็กเปิด-ปิด <tag>...</tag>

แท็ก หน้าที่
<h1> ถึง <h6> สำหรับทำหัวข้อข่าวหรือหัวเรื่อง (Heading)
<p> สำหรับพิมพ์ข้อความเนื้อหาทั่วไป (Paragraph)
<img src="..."> สำหรับใส่รูปภาพบนหน้าเว็บ (Image)
<a href="..."> สำหรับทำลิงก์เชื่อมโยงไปหน้าอื่น (Hyperlink)
<button> สำหรับสร้างปุ่มกด (Button)

3เคล็ดลับการแต่งเว็บด้วย CSS สไตล์มินิมอล

Color & Background

การใส่สีข้อความ color: blue; และสีพื้นหลัง background-color: #f0f0f0;

Font Styling

การเปลี่ยนฟอนต์ font-family และปรับขนาดตัวอักษร font-size

Spacing

การจัดระยะห่างขอบและช่องไฟด้วย margin และ padding

4เครื่องมือลงมือทำจริง (Beginner Tools)

Code Editor แนะนำ

• Online
Replit, CodePen, JSFiddle (เปิดเว็บแล้วพิมพ์โค้ดทดลองได้ทันที)

• Offline
Visual Studio Code (VS Code) หรือ Notepad++
